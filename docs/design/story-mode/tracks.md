# 《余页》主线选曲与核验记录

> 配套 [故事大纲](./outline.md)。32 首不同曲目：phi 19 首、ptc 13 首。编号用于关卡槽，不强制第 2／3／4 章的游玩顺序。

## 1. 选取依据与核验范围

本次设计实际查询了项目配置的目录，不假定流行曲目一定已经收录：

- PhiCommunity：<https://charts.phicm.focalors.ltd/content.json>，以及各曲目 `meta.json`。
- PhiTogether：<https://ptc.focalors.ltd/chapters.json>，所列的社区曲目目录 <https://ptc.realtvop.top/pt_songs.json>。
- 项目来源和难度映射参考 `src/lib/sources.ts`、`src/lib/meta.ts`、`src/lib/playLoader.ts`。
- 现有项目仓库：<https://github.com/PhiGameRevive/PhiCommunityRevive>。

**本轮已做：**

1. 查询全部入选曲目的目录与元数据，确认曲名、来源 ID、可用难度及谱面文件。
2. 对 32 个入选谱面 URL 发出 HEAD 请求，均收到 HTTP 200。
3. 使用 `ffprobe` 读取 32 个对应在线音频的媒体时长，全部成功；合计 **5209.869 秒，即 86 分 49.869 秒**。
4. 对 phi 条目核对目录名与元数据 `codename` 一致。

**本轮没有做：**

- 没有逐首在 Phaser 中游玩、核对谱面最后判定时间、BGA、附加资源、故事板、闪光与设备性能。
- 没有试听后逐秒标定音乐高潮，不能把选曲情绪定位当作已验证的音画同步点。
- 没有证明所有部署节点均有相同 CORS、稳定性和文件内容；HTTP 200 不等于谱面可正确解析。
- 没有取得任何新的音频改编／再分发授权，未将歌曲下载并打包进故事资产。

媒体时长支持预算，但最终采用引擎内完整演奏时长。若谱面在曲终前后结束，须调整实际内容账，而不是隐藏差异。

### 地址规则

- 表中 phi 项目当前完整地址为 `https://charts.phicm.focalors.ltd/{去掉phi-的codename}/{URL编码后的文件名}`；运行时仍遵循项目现有部署节点谱面源选择，不把本次探测主站硬编码为唯一域名。
- 表中 13 个 ptc 项目的当前地址均为 `https://ptc.realtvop.top/song/{去掉ptc-的id}/{文件名}`；最终加载使用目录给出的完整 URL，不按其他 PTC 条目的习惯猜地址。
- `Gray` 是该谱面自己的难度名，项目中映射为 `sp`，不是标准 IN；`星茶会` 的定数原值为 `?`，不能填一个看起来合理的数字。
- `Light` 另有 AT 16，本稿只计一次 IN 14，不通过重打 AT 增加主线时长。
- `Inverted World` 在来源间存在同名条目，本稿明确选择 phi 的 `invertworld`，不能只按曲名匹配切到另一个来源。

## 5. 内容与可用性发布门禁

每个槽位进入实现前建立独立记录：

1. 固定来源、codename、难度、谱面与音频身份，保留作者／谱师署名；内容更新后复核，不只按标题搜索。
2. 实机加载完整谱面，确认所需资源、转换、音画同步、实际结束时间和结算路径。
3. 审看原谱自带动画、闪光、恐怖画面和音量变化；T17 尤其需要，不能用本稿的内容警示代替实际检查。
4. 逐项测试手动、伴奏、纯聆听三种故事完成路径，不污染普通成绩数据。
5. 每首准备曲前任务、曲后回应、世界状态回执；自动演奏不是一张等待倒计时的空白界面。
6. URL 不可达时先提供重试／已有合法缓存。若要换谱，必须实际核实替代曲及资源，更新剧情衔接和内容版本，不能静默换成任意歌曲。
7. 因外部谱面临时下架无法加载时，可提供明确标记的剧情演出摘要以免软锁；这属于故障兜底，会缩短本次体验，不拿它宣称完整音乐流程仍有相同时长。
8. 本稿没有凭空填入备用曲名或备用 URL。需要替换时由后续选曲核验处理，不编造可访问性或权利许可。
9. 按原游戏的运行时谱面获取方式使用媒体，不将曲目剪辑进新增过场视频，不擅自镜像整个谱库。

## 6. 尚需制作，而不是尚待编造的内容

这份表已经完成大纲阶段的实际选曲。曲目归属与难度来自目录、媒体时长来自工具探测；曲目情绪与故事用途属于创作编排，最终仍需试听与实机调整。

真正需要用户再决定的，是未来若要越出已确认边界的事项，例如购买音乐、外包配音、改为付费服务或永久镜像第三方资源。当前方案没有默认这些授权。
