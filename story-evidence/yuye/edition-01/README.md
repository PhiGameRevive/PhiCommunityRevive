# 《余页》第一版排演资料／虚构故事线索

本目录是《余页》的虚构剧情资料，不是项目维护记录，也不描述现实中的人物或事故。
`runtime/collate.ts` 只供阅读，不作为校订器执行；游戏以原始文本导入本目录，提供同版完整镜像。

## 阅读目录

- [来稿：records/rain-night.txt](./records/rain-night.txt)——发生了什么／属于哪一版。
- [授权：rights/bai-yu.txt](./rights/bai-yu.txt)——这些材料可以怎样使用。
- [工作规则：runtime/collate.ts](./runtime/collate.ts)——排演器实际上选了什么。

请在三个文件之间核对，不需要提交代码修改。
来稿验收、当前授权、排演索引是三种不同的记录，不能用其中一项代替另外两项。

## 发行与镜像

资料集标识：`yuye/edition-01`。
站内源码阅览室直接展示以上文件及本说明的全文，路径与本目录一一对应。
发布者须先将本目录提交到真实仓库，再以实际存在的完整 40 位提交 SHA 配置构建变量
`VITE_STORY_ARCHIVE_REVISION`，重新构建后才提供该提交的外链。
未配置冻结提交时，站内显示“尚未发布的源码线索”，不以 `main` 冒充冻结版本。
提交不存在或外网不可达时，完整的随包镜像仍可阅读；网络错误不是剧情证据。

这三份文件只陈述故事中的来稿、授权及原工作规则。
现实设施的安全状况不能由虚构演绎证明。
